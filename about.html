About UMRoomFaultReporter

UMRoomFaultReporter is a centralized web application designed to streamline the reporting and tracking of broken or damaged facility equipment in classrooms across the University of Mindanao Digos College (UMDC).

This system allows students, faculty, and university personnel to quickly report issues—such as broken air conditioners, faulty projectors, damaged chairs, and lighting errors—so the campus maintenance team can address them promptly.

Developer's Note & Educational Purpose

This system was created purely as an educational project to fulfill the coursework requirements for my Information Management class.

I am incredibly proud to share that this is my very first website and fully functional web application! Building this system from scratch—from designing the frontend interface to wiring it up to a live PostgreSQL cloud database via Supabase—has been an amazing learning journey into the world of software development.
