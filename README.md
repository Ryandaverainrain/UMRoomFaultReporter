# UMRoomFaultReporter 🛠️

A centralized web application designed to streamline the reporting and tracking of broken or damaged facility equipment in classrooms. Built from scratch as a fully functional frontend interface connected to a live cloud database.

## 📋 Overview
This system allows students, faculty, and university personnel to quickly report issues—such as broken air conditioners, faulty projectors, or damaged chairs—so the campus maintenance team can address them promptly. 

## ✨ Features
* **Role-Based Reporting:** Tailored submission forms for both students and faculty members.
* **Live Ticket Tracking:** Public view of active maintenance reports and their current statuses.
* **Secure Admin Dashboard:** Protected login for maintenance personnel to view, manage, and resolve tickets.
* **Cloud Database Integration:** Real-time data storage and retrieval.

## 💻 Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend/Database:** Supabase (PostgreSQL)
* **Hosting/Deployment:** Vercel
